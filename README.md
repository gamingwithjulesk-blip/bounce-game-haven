# bounce-game-haven

this game is a platformer game about a bouncy ball that was left at its owners grandmas house and is determinded to find its way back to its owner. (idk why it has a consuisness jst roll with it) 

you play as the ball. use the arrow keys to control it. 

this game was made for haven ottawa 2026. 

the tools we used to make this game are godot, github, pixelorama, spritebuff.com, pixilart, and https://opengameart.org/content/meadow-thoughts for music (the song we used is medow thoghts by Écrivain)

we also modeld our bouncy ball charecter after the bouncy ball from toy story.

art and assets were created by liam caralson aka willybilly on git. 

script, level design, ball charecter design, and godot work was done by me (jules kingsland aka gamingwithjules on git and itch)

some of the script was godot script templates, most if not all were slightly altered by me. 

ai was used on this project for debuging some praticullarly difficuly bugs. (i used gemini/google image serch.)
